# Student-Record-Management-System

Student Record Management System
<br>
📌 Project Overview

The Student Record Management System is a beginner-friendly Python project designed to manage student names and marks efficiently. The project demonstrates how Python dictionaries can be combined with JSON file handling to create a simple system for storing, updating, searching, and displaying student records.

The main goal of this project is to practice fundamental Python concepts while building a practical application that can store data permanently. Unlike a basic dictionary program where data is lost when the program closes, this project uses a JSON file to save student information so that the data can be accessed again when the program is restarted.

🚀 Features
1. Add Student

Users can add a new student by entering:

Student name
Student marks

The new student record is automatically saved to the JSON file.

2. Update Student Marks

Users can search for an existing student by name and update their marks.

The updated marks are also permanently saved in the JSON file.

3. Search Student

Users can search for a particular student by entering their name.

If the student exists, the program displays:

Student name
Student marks

If the student does not exist, the program displays an appropriate message.

4. Display All Students

The program can display all available student records in a simple format containing:

Student name
Marks
